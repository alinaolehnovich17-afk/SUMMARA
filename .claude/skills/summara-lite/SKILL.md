# SUMMARA Lite — сообщение → структурированный документ

Лёгкая версия SUMMARA: берёт свободный текст (или расшифровку голоса) и превращает
его в аккуратный документ по одному из трёх шаблонов. Работает «как есть», только
средствами Claude — без Whisper, Gradio и API.

## Как действовать

1. **Получи текст.** Если пользователь дал аудио/расшифровку — используй её текст.
2. **Определи тип** (один из трёх):
   - **meeting** — если есть встреча/совещание/созвон/собрание/переговоры —
     даже в контексте планирования («провести», «организовать», «запланировать»).
   - **bug_report** — если описана ошибка/неисправность/сбой/краш.
   - **task** — во всех остальных случаях (поручение, задача, действие).
3. **Извлеки поля** строго из текста. Не выдумывай факты (даты, имена, цифры).
   Чего нет — помечай «не указан(а/о)».
4. **Выведи Markdown** по соответствующему шаблону ниже — ровно в этом формате
   (заголовок `## `, строки `**Метка:** значение`, списки). Это и есть результат.
5. **Если просят «живее»** — можно расширить значения примерами и пояснениями,
   добавить сноски `[1]` и раздел `## Пояснения` в конце, НО сохранить структуру строк.

## Шаблоны вывода

### task — Задача
```markdown
## Задача: <краткое название>
**Описание:** <что нужно сделать, подробно>
**Исполнитель:** <кто или «не указан»>
**Срок:** <когда или «не указан»>
**Приоритет:** <high / medium / low>
```

### meeting — Итоги встречи
```markdown
## Итоги встречи: <тема>
**Дата:** <дата или «не указана»>
**Участники:** <через запятую или «не указаны»>

**Решения:**
- <решение 1>
- <решение 2>

**Следующие шаги:**
- <шаг 1>
- <шаг 2>
```

### bug_report — Баг
```markdown
## Баг: <краткое название>
**Серьёзность:** <critical / high / medium / low>
**Описание:** <в чём проблема>

**Шаги воспроизведения:**
1. <шаг 1>
2. <шаг 2>

**Ожидаемое поведение:** <как должно быть>
**Фактическое поведение:** <как есть на самом деле>
```

## Пример

**Вход:** «Надо до пятницы подготовить квартальный отчёт по продажам, ответственный Иван, это срочно»

**Выход:**
```markdown
## Задача: Подготовить квартальный отчёт по продажам
**Описание:** Свести данные по продажам за квартал и оформить отчёт.
**Исполнитель:** Иван
**Срок:** до пятницы
**Приоритет:** high
```

## Правила
- Язык вывода — как у входного сообщения (по умолчанию русский).
- Возвращай ТОЛЬКО готовый Markdown-документ, без преамбул вроде «Вот результат».
- Сохраняй формат строк — по нему документ потом можно красиво оформить (PDF/HTML).
