# SUMMARA — Руководство пользователя

## Что делает программа

**SUMMARA** — это веб-приложение, которое преобразует голосовые или текстовые сообщения в структурированные рабочие инструкции.

Вы говорите (или пишете) что нужно сделать, например:
> «Поручить Марине редизайн главной страницы до пятницы, приоритет высокий»

Программа автоматически:
- распознаёт речь в текст (Whisper)
- определяет тип инструкции (задача / встреча / баг-репорт)
- извлекает исполнителя, срок, приоритет и описание
- проверяет полноту и качество
- формирует готовый документ

Документ можно скачать в форматах **Markdown, TXT, JSON или PDF** (4 стиля оформления).

## Запуск программы

```
python app.py
```

Затем открыть браузер: **http://localhost:7860**

## Как пользоваться

### Шаг 1 — Введите задание

**Голосом:**
1. Перейдите на вкладку «Голос»
2. Нажмите кнопку микрофона, продиктуйте задачу, остановите запись
3. Текст появится автоматически

**Текстом:**
1. Перейдите на вкладку «Текст»
2. Введите задачу в поле «Текст сообщения»

### Шаг 2 — Сгенерируйте инструкцию

Нажмите кнопку **«Сгенерировать инструкцию»**.

Справа появятся:
- определённый шаблон (Задача / Встреча / Баг-репорт)
- оценка качества (1–10)
- готовая инструкция в поле «Готовая инструкция»

### Шаг 3 — При необходимости отредактируйте

Поле «Готовая инструкция» **редактируемое** — можно исправить любой текст прямо в поле.

После правок нажмите **«Подтвердить инструкцию»**.

### Шаг 4 — Скачайте файл

В блоке «Экспорт»:
1. Выберите формат: `Markdown (.md)`, `Текст (.txt)`, `JSON` или `PDF`
2. Для PDF дополнительно появится выбор стиля оформления:
   - **Лавандовый** — голубая шапка, декоративные ветки
   - **Розовый** — малиновая шапка, декоративные ветки
   - **Редакционный** — тёмная шапка, золотые акценты
   - **Минимальный (подложка)** — только фоновое изображение с книжками, без оформления
3. PDF создаётся автоматически после выбора стиля
4. Для Markdown/TXT/JSON нажмите кнопку **«Скачать»**

### Кнопка «Очистить»

Сбрасывает все поля и позволяет начать заново.

## Структура файлов

```
summar/
├── app.py                  — главный файл, запуск приложения
├── pipeline.py             — оркестрация: транскрипция → классификация → извлечение → валидация
├── config.py               — пути и настройки
├── requirements.txt        — зависимости Python
├── .env                    — API-ключ (не публиковать!)
├── .env.example            — пример .env без секретов
├── agents/
│   ├── transcription.py    — распознавание речи (faster-whisper)
│   ├── classifier.py       — определение типа инструкции (Claude API)
│   ├── extractor.py        — извлечение полей (Claude API)
│   ├── validator.py        — проверка качества (Claude API)
│   └── pdf_export.py       — генерация PDF (ReportLab, 4 стиля)
├── templates/              — YAML-шаблоны: task, meeting, bug_report
├── models/                 — Pydantic-схемы данных
├── exports/                — папка для сохранения сгенерированных файлов
├── pdl/                    — фоновые изображения для PDF
└── stl/                    — референсные картинки стилей
```

## Использование через Claude Desktop (MCP)

MCP позволяет использовать SUMMARA прямо в чате с Claude — без открытия браузера.

### Установка (один раз)

```bash
pip install -r requirements.txt   # mcp уже включён
```

Открыть файл конфига Claude Desktop:
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`

Вставить (заменить пути на свои):

```json
{
  "mcpServers": {
    "summara": {
      "command": "C:/путь/к/summara/.venv/Scripts/python.exe",
      "args": ["C:/путь/к/summara/summara_mcp/mcp_server.py"]
    }
  }
}
```

Перезапустить Claude Desktop.

### Как пользоваться

Написать в чат Claude Desktop:

> *«Создай инструкцию: поручить Марине редизайн главной страницы до пятницы»*

> *«Сгенерируй задачу для Ивана — разработать модуль авторизации, срочно, и сделай PDF»*

Claude сам вызовет SUMMARA и вернёт результат в чат.

### Доступные команды для Claude

| Инструмент | Что делает |
|---|---|
| `generate_instruction` | Генерирует инструкцию из текста |
| `generate_instruction_with_pdfs` | Генерирует инструкцию + **все 4 PDF** в папку `exports/` |
| `export_pdfs` | Создаёт 4 PDF из готового текста инструкции |
| `transcribe_audio` | Транскрибирует аудиофайл в текст |

### Результаты

Все созданные PDF автоматически сохраняются в папку `exports/` с именами:
```
exports/instruction_20260603_143022_lavender.pdf
exports/instruction_20260603_143022_pink.pdf
exports/instruction_20260603_143022_editorial.pdf
exports/instruction_20260603_143022_minimal.pdf
```

## Перенос на другой компьютер

### Требования

- Python **3.10 или новее**
- Интернет-доступ (для работы Claude API)
- Достаточно RAM: ~2 ГБ (модель Whisper `base` загружается в память)
- На Windows: шрифты Arial, Times New Roman, Calibri должны быть установлены (обычно уже есть)

### Инструкция по переносу

**1. Скопируйте папку проекта** на другой компьютер (USB, архив, git clone).
Важно: папку `.venv` копировать **не нужно** — она будет создана заново.

**2. Создайте файл `.env`** в корне проекта:
```
ANTHROPIC_API_KEY=ваш_ключ_здесь
```
API-ключ получить на сайте: https://console.anthropic.com

**3. Создайте виртуальное окружение и установите зависимости:**

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**4. Установите Playwright** (если нужен — только для разработки, не для работы приложения):
```bash
playwright install chromium
```

**5. Запустите приложение:**
```bash
# Windows
.venv\Scripts\python app.py

# Linux / macOS
.venv/bin/python app.py
```

Откройте браузер: **http://localhost:7860**

### Важные замечания при переносе

- Файл `.env` с API-ключом **не включается** в архив/репозиторий — его нужно создать вручную на каждом компьютере
- Папку `exports/` можно перенести вместе с проектом — там хранятся ранее созданные файлы
- На Linux шрифты Arial и др. нужно установить отдельно или программа автоматически использует системные шрифты как fallback
- Модель Whisper (`base`) скачивается автоматически при первом запуске (~150 МБ), интернет нужен один раз

### Проверка после переноса

После запуска откройте http://localhost:7860 и выполните:
1. Вкладка «Текст» → введите любую задачу → нажмите «Сгенерировать» → должна появиться инструкция
2. Выберите формат PDF → выберите стиль → должен скачаться файл

Если возникает ошибка `ANTHROPIC_API_KEY` — проверьте файл `.env`.
